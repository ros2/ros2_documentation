Contributing to ROS
=========

**Area: Community, Contributing, | Content-type: about | Experience: beginner, intermediate, advanced**

.. contents:: Table of Contents
   :local:

ROS is an open source set of tools and libraries and contributors are an important part of our community. Whether you are a developer, researcher, company, or student, contributing to our open source software helps us to grow and improve. Thanks to the contributions of our community members, it is easy to share code, exchange ideas, and work together on projects.

This page presents the ways in which you can contribute to ROS.

Your first contribution
-----------------------
ROS makes it easy to contribute, and anyone can participate. Depending on your skills and experience, you can review and update the ROS documentation, contribute code,or fix bugs.

For example, if you are a complete beginner, you could start with some beginner tutorials, checking them for accuracy as you work through the tasks. If you are a developer familiar with ROS,you could try fixing bugs, or suggesting improvements.

Contributing to documentation
-----------------------------

Contributing to ROS documentation is a great way to learn about ROS. Contributing to the documentation includes reviewing tutorials, how-to guides, and similar content to make sure they are accurate, up to date, and still work as expected. Anyone can take part, from beginners checking instructions to experienced contributors updating the documentation after fixing bugs or adding features.

Contributing to code
--------------------

Contributing code involves reviewing an existing project, and making improvements like fixing bugs or adding features, and submitting those changes for review so they can be included in the shared codebase.

Anyone can contribute to our open source code, from complete beginners to experienced developers.For complete beginners, simple contributions can include fixing small mistakes or improving documentation are a great entry point. Experienced developers can contribute at a deeper level by designing new features, reviewing code contributed by other community members,or fixing complex bugs.

Reporting bugs
--------------

Reporting bugs involves identifying and describing problems in the software so they can be fixed.

Bugs can be reported by anyone who uses the software, regardless of experience. A beginner who spots a bug when following a tutorial can report it and include the steps needed to reproduce the issue. More complex bug reports usually include detailed technical information to help developers quickly understand and fix the issue.
