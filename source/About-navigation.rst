Navigation
==========

Navigation capabilities enable a mobile robot to map its environment, plan a path to its destination, and safely follow that path while adapting to unexpected changes.
This article summarizes ROS developer tools and guidance available to help with navigation.

**Area: perception, capabilities | Content-type: about | Experience: beginner, intermediate, expert**

.. contents:: Table of Contents
   :local:

Summary
-------

Navigation capabilities are focused on producing maps of an environment, then planning a path through that environment for a mobile robot to travel to its destination, and finally controlling the robot to move along that path - including handling unexpected events that arise as it moves.
